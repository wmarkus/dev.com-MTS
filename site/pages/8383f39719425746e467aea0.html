Tech Espresso is a series of webinars focused on technical topics related to skilling startup developers. This will cover most widely used tech stacks / technologies used by startups along with solutions to common issues startups face when building their applications on Azure. This will cover a wide swathe of topics from Oct 2022 - June 2023 including IaaS, building your first app on Azure, containers, security, AI, Databases, IoT and more. This will help startup developers to build secure, reliable and scalable applications on Azure

    Automating AKS cluster creation using Bicep and Azure DevOps | #Techespresso

    10:30 AM - 11:30 AM (UTC)

    The session will focus on automating the creation of a private Azure Kubernetes Service (AKS) cluster and its associated resources using Bicep templates and Azure DevOps. What will you learn from this session: In this scenario, you'll explore how to deploy a private Azure Kubernetes Service (AKS) cluster using Bicep templates in combination with Azure DevOps. By leveraging Bicep templates, you can define the desired state of your infrastructure as code, including the private AKS cluster, virtual networks, and related resources. Azure DevOps provides a powerful continuous integration and continuous deployment (CI/CD) pipeline that automates the deployment process. With this approach, you can ensure a secure and isolated environment for your AKS cluster while leveraging the robust capabilities of Azure DevOps for seamless integration, testing, and deployment of your containerized applications.
