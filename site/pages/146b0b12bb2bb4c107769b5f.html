    Microsoft Build //localhost:Beijing ——微软中国开发者日：Ready？构！

    1:30 AM - 3:30 AM (UTC)

    站在AI技术变革的关键节点，开发者正加速寻找从模型能力到应用价值的转化路径。如何将AI智能体应用与开发者工具链推进到实际业务场景中，成为当下核心议题。 这一次，你不只是参与者，更是构建者。来和我们一起 Ready？构！ “Microsoft Build //localhost:Beijing——微软中国开发者日：Ready？构！”于6月18日正式启幕。上午的主题演讲将在线上同步开启，诚邀您一起聚焦微软 Build 2026 创新动态，解锁前沿转型实践。就是现在！填写页面右侧注册表单，即可轻松参与线上直播。更有线上抽奖环节，惊喜好礼等你解锁 大会主题演讲核心亮点 “构”见前沿-微软 Build 2026 新发布 聚焦微软 Build 2026 创新技术动态，快速了解AI 智能体、智能GitHub Copilot副驾驶®（国际版）、Microsoft Foundry（国际版）等热门话题。 “构”解转型-CTO解读前沿转型 微软中国CTO韦青将深度解读前沿转型，分享AI时代的技术趋势与应用路径。 大会主题演讲议程： 09:30 - 10:00 微软 Build 2026 新进展与前沿转型 分享嘉宾：韦青 微软中国CTO 10:00 - 10:45 微软开发者的一天：我如何使用智能 GitHub Copilot副驾驶®（国际版）以及微软AI工具提升ROI 分享嘉宾：胡久林 微软首席软件工程经理 10:45 - 11:30 使用 Microsoft Foundry（国际版）的前沿模型，驱动你的业务 Agent Harness 分享嘉宾：卢建晖 微软高级云技术布道师 直播不够尽兴？不如来现场！在 GitHub 午间派对中放松交流，领取惊喜礼品，与微软产品专家面对面探讨开发实践，并在动手实验环节打造新一代 Agentic AI Apps。想要参与现场活动？点击链接了解详情：https://msevents.microsoft.com/event?id=2014972057
