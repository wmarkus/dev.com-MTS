PowerToys

Make Windows work the way you do. Get more than 30 free, open-source tools that help you find things fast, arrange windows, and paste smarter.

Popular tools

Big time savers, one shortcut away

Start with the tools people use every day. Turn on only the ones you need.
Find anything fast with Command Palette

Press Win + Alt + Space and start typing. Open apps, files, and commands, and add extensions to make it your own.

 Arrange your windows with FancyZones

Create your own window layouts and snap apps into place. Press Win + Shift + ` to open the layout editor.

 Paste smarter with Advanced Paste

Press Win + Shift + V to paste as plain text, Markdown, or JSON. You can also use AI to change text, with online or local models.

 Preview files with Peek

Select a file in File Explorer and press Space to see a quick preview. No need to open another app.
