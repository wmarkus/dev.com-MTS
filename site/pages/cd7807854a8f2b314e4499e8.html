Get ready to unleash your creativity at the Powerful Devs Conference + Hackathon 2025! This is the ultimate event for developers who want to tap into the full potential of the Power Platform for enterprise app development. Join us for a one-day online extravaganza followed by a two-week hackathon where you'll learn to build smarter, faster, and with less effort.

Register for the hack here.

Review our sessions below and click "details" to learn more and register for a specific stream. Don't want to miss a thing? Select "Register for the Series" for a one-click option to register for both the conference and hackathon. Registering for at least one livestream is required to be eligible to submit your hack.

    Powerful Devs Conference 2025

    4:00 PM - 10:30 PM (UTC)

    Join us for Powerful Devs Conference 2025, which will highlight how developers can leverage the Power Platform to build applications faster and with far less effort! Connect with industry recognized ProDev influencers, Microsoft Cloud Advocates, trusted and diverse community leaders, and members of the Power Platform Team. Hosted by Scott Durow and Kendra Springer! Register today and find the complete agenda below: | Session Time (PT) | Session Title | Speaker(s) | Session Description | | ---------------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | | 8:05 AM | Powerful Devs Conference Keynote | Leon Welicki | Dive into the world of intelligent apps and processes with Leon Welicki as he kicks off the Powerful Devs Conference and shares how to build secure enterprise-level solutions and processes as a professional developer using the capabilities of the Power Platform and AI. | | 8:55 AM | Maximize the value of generative AI in Copilot Studio | Lauren Mills | Discover Copilot Studio's AI features, their functionality, and usage. Learn how to combine them to create powerful, engaging user experiences, simplifying development and design processes, and learning the skills to debug, troubleshoot, and improve Generative AI behavior, enhancing developers' efficiency and innovation. | | 9:30 AM | No more secrets! Using managed identities in Dataverse plugins | Magnus Sorensen | Learn to use Managed Identities in Dataverse plugins to safely authenticate with Azure endpoints, without secrets. From a new Dataverse and Azure environment to a modern secure integration, you will be able to update your code to the latest security standards. | | 10:05 AM | Get your code together! | Marcel Ferreira; Albert-Jan Schot | Discover how integrating source code with Power Apps transforms app building. Learn to use source code for scaffolding and applying custom business checks, such as naming conventions, in your ALM process. This approach ensures cleaner, more maintainable solutions in the long term. | | 10:45 AM | The different flavors of ALM in the Power Platfrom: Which is right for you? | Feline Parein | Discover how to start with ALM in the Power Platform. This session covers Pipelines for Power Platform, Power Platform Build Tools, and the ALM accelerator, explaining their differences and usage. Learn when and how to use each tool effectively. | | 11:20 AM | Building cross platform desktop apps with Dataverse and .NET MAUI | Carl Cookson | Explore Dataverse's capabilities for managing data and .NET MAUI for developing native apps from a single codebase. Build a simple starter app leveraging both tools to streamline development and create cross-platform applications. Ideal for developers seeking efficiency and powerful solutions. | | 11:55 AM | Extend your Copilot with connectors | Mankirat Kaur Bajwa; Nathan Helgren | Learn how to effortlessly extend the capabilities of Microsoft 365 Copilot using connectors. Explore how Actions enable create, update, and delete functions, which can also integrate with declarative or custom agents. | | 12:30 PM | 5 ways to leverage Power Pages VS Code Copilot to increase productivity | Victor Dantas | This session demonstrates how to use Visual Studio Code Copilot to boost productivity in Power Pages development. Learn to optimize Liquid templating, accelerate JavaScript tasks, gain insights into JavaScript, create seamless HTML with Bootstrap, and optimize web API calls efficiently. | | 1:05 PM | Mastering automated testing in Power Platform: From unit tests to CI/CD integration | Grant Archibald | Join this in-depth session on automated testing in the Power Platform. Learn how to address common challenges, insights into approaches to test and monitor solutions, how to build robust applications, integrate quality gates into CI/CD, and how to apply engineering excellence principles to both code-first and low-code development. | | 1:45 PM | Building mega apps with the Power Platform | Rami Mounla | Discover how DXC and Microsoft's FastTrack team delivered a scalable passport and citizenship case management solution for New Zealand's DIA using the Power Platform and Azure. Learn about the journey, lessons learned, and the epic go-live success from the lead architects.|
