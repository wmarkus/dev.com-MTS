Learn Live: Master the Skills to Create AI Agents

  • Format:
  • Livestream

Topic: Agents

Language: English

  • Events in this Series:
  • 6

This series is designed to help you complete the official Microsoft Plan on Learn for mastering the latest agentic AI technologies. Generative Artificial Intelligence (AI) is becoming more functional and accessible, and AI agents are a key component of this evolution. This Learn Live series will help you understand the AI agents, including when to use them and how to build them, using Azure AI Agent Service and Semantic Kernel Agent Framework. By the end of this learning series, you will have the skills needed to develop AI agents on Azure.

Want to continue your learning? Check out these related sessions:

  • AI Agents Hackathon and Expert Sessions
