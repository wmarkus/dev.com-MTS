Join the global "Season of AI" for an in-depth exploration of AI’s latest advancements, focusing on the transformative role of "copilots" across various platforms. Running from October 1 through December 30, 2024, this event series brings together developers, AI enthusiasts, and industry leaders in a worldwide discussion on tools like GitHub Copilot, Microsoft 365 Copilot, and Azure’s build-your series offers rich resources for both beginners and advanced practitioners eager to deepen their AI skills and understand how copilots are reshaping productivity, development, and collaboration.

    Vision to Visualisation: Using GitHub Copilot for Azure, Python, and Diagrams

    12:00 PM - 1:00 PM (UTC)

    In this talk, we will explore the transformative capabilities of using GitHub Copilot and the GitHub Copilot extension for Azure in VSCode for cloud deployments and architectural analysis. We will learn how to harness the power of AI to seamlessly deploy technical system architectures into Microsoft Azure, simplifying complex processes and enhancing productivity. We will demonstrate how GitHub Copilot can assist in writing deployment code, enabling efficient resource provisioning in Microsoft Azure. Additionally, we will delve into the creation of a Python script using Copilot to also analyse existing Azure deployments. This analysis will include converting existing deployment resources into JSON format and use this data with AI to generate detailed architectural diagrams and documentation using Mermaid diagrams to visualise and diagram the architecture making it easier to see how everything fits together visually. By the end of this session, you will gain a deeper understanding of how GitHub Copilot can be leveraged to not only create and deploy resources and technical system architectures but also to analyse, document and diagram existing ones. Harnessing the power of GitHub Copilot does not only have to be for developers and the demo will show you how GitHub Copilot can benefit and empower cloud architects, security analysts, DevOps engineers and developers alike to better understand and document their infrastructures hosted in Microsoft Azure, ultimately driving greater efficiency, security, clarity and understanding of their cloud hosted landscape in Microsoft Azure.

    Season of AI - Empowering Developers

    3:30 PM - 6:30 PM (UTC)

    Join us for an evening dedicated to exploring the forefront of artificial intelligence, tailored specifically for developers eager to harness AI's power in their projects. Hosted at the Microsoft Reactor in Tel Aviv, this event brings together expert speakers, hands-on demonstrations, and inspiring discussions to ignite your journey into the world of AI. Sessions The evening starts with Tal Cohen from ZioNet presenting "Coding the Future of AI" based on insights from Microsoft Ignite. Tal will demonstrate a shift in software development, integrating deterministic code with prompt-based AI and evaluation tests. Using tools like Azure Foundry SDK & Portal and Semantic Kernel, developers can merge traditional imperative code with advanced AI services. This session aims to inspire attendees to explore new possibilities in AI-driven software development. Following this, Alon Fliess will take the stage to delve into the fascinating realm of Small Language Models (SLMs). Alon will highlight why SLMs are vital for lightweight, efficient AI applications, demonstrating the Phi3 SLM running locally and in the cloud. Attendees will also learn about other compact models, such as llama2.c, and gain insights into fine-tuning SLM models for specific needs. This session aims to empower developers with practical tools and knowledge to adopt SLMs in real-world scenarios. The final session features Alon Fliess in a fireside chat with ZioNet developers. This discussion explores the challenges, patterns, and practices of integrating AI into software projects. Using real-world examples, presenters will share their AI experiences to inspire attendees to begin their own AI journeys. This event is an opportunity to learn, engage, and connect with peers who are passionate about innovation. Whether you’re an experienced developer or just beginning to explore AI, you’ll leave with fresh insights, practical knowledge, and the inspiration to take your projects to the next level. 17:30 - 17:50 Registration & Networking Guests arrive, check in, and enjoy light refreshments while networking. 17:50 - 18:00 Opening Remarks Host: Alon Fliess Welcome attendees and provide an overview of the evening's sessions. First-hand insights from the Microsoft Ignite conference 18:00 - 18:45 Session 1: Coding the Future of AI Speaker: Tal Cohen, ZioNet Based on insights from Microsoft Ignite, Tal will demonstrate the fusion of deterministic code with prompt-based AI LLM calls. Learn how tools like Azure Foundry SDK and Semantic Kernel reshape software development. 18:45 - 19:00 Pizza Break 19:00 - 19:45 Session 2: Exploring Small Language Models (SLMs) Speaker: Alon Fliess Dive into the SLMs and their importance in lightweight, efficient AI applications. Witness a live demonstration of the Phi3 SLM. Learn about compact models and gain insights into fine-tuning for tailored applications. 19:45 - 20:15 Session 3: Fireside Chat - AI in Software Projects Moderator: Alon Fliess Presenters: ZioNet Developers Engage in a dynamic discussion on the challenges and patterns of integrating AI into projects. Gain inspiration and practical guidance through real-world scenarios to embark on your AI journey. 20:15 - 20:30 Q&A and Wrap-Up Audience questions for speakers. Closing remarks and next steps for attendees.
