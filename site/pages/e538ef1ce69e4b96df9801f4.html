About this series:
Join us for an immersive Copilot Developer Camp, Copilot developer camp is a virtual workshop for professional developers who want to learn how to extend Copilot for Microsoft 365 or build their own copilots. This camp is a free, one-day workshop post-AI tour. The goal is to empower developers, ISVs, and tech enthusiasts with the knowledge and skills to extend Copilot for Microsoft 365 by offering in-depth understanding and practical experience.

Who is it aimed at?
Developers, ISV partners, product-centric companies, or enterprise developers

Why should I attend?
Understand the capabilities of Microsoft 365 Copilot and its extensibility AI models.  What are the different methods to develop Copilot agents utilizing Microsoft 365 Copilot's AI and orchestration How to create a Custom engine agent using Azure AI Studio and Teams AI library How to developing a Declarative agent that includes a Build custom action for your agent via API plugins.

Learn more about Copilot Developer Camp:
https://aka.ms/copilotdevcamp
