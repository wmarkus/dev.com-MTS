    微软技术直通车第二十六期，将于2025年9月20日面向大家。活动将采用嘉宾现场技术分享的方式进行。微软VS Code产品团队启动的VS Code Dev Days活动是一项全球计划，旨在为世界各地的技术社区带来AI编程的亲身体验。目标是将开发人员、爱好者和当地社区聚集在一起，探索Visual Studio Code和GitHub Copilot在自主 AI 开发中的强大功能。VS Code Dev Days向所有开发人员开放，重点关注使用 GitHub Copilot 进行实用的 AI 辅助编码。VS Code Dev Days重在提供实践体验，让参与者边做边学。我们提供了介绍性和研讨性的讲座以及动手实验的内容。 注意：请一定带上你的笔记本电脑！动手实验课程需要用到您自己的设备，以便您可以实时练习新技术。 本期活动是由微软最有价值专家（Microsoft MVP）、微软技术直通车（MSTECHLNK）和软积木联合主办，同时得到微软 Reactor 的礼品和视频直播支持，将给您带来不同的期待和更加沉浸的技术体验，敬请参与。 活动日程： 13:30-14:00 签到 14:00-14:05 活动致辞 14:05-14:45 高效AI开发指南：VS Code中GitHub Copilot实践技巧 - 朱一婷 - 微软技术社区区域总监，微软开发者技术方向最有价值专家 14:45-15:05 合影/休息 15:05-15:45 从Vibe Coding到Spec-Driven的GitHub Copilot編程 - 卢建晖 - 微软高级AI+云布道师 15:45-15:55 会间休息 15:55-16:35 使用GitHub Copilot辅助C#开发 - 郝冠军，微软最有价值专家（Microsoft MVP） 16:35-16:45 会间休息 16:45-17:25 动手实验一 使用MCP扩展GitHub Copilot能力 - 朱钢 - 微软MVP，U3D工程师，eSimu工业智能系统服务端架构负责人 17:25-17:30 结束
