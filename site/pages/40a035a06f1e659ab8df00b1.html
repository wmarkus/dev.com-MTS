Microsoft AI Genius Series에 오신 것을 환영합니다!

AI 과장 광고에 휘둘리기보다, 실제로 작동하는 지능형 에이전트를 만들고 싶다면
Microsoft AI Genius Series에서 시작해보세요.

Microsoft AI Genius Series란?
Microsoft AI Genius Series는 개발자 중심 프로그램으로, AI 개념을 실제 운영 가능한(프로덕션 레디) 솔루션으로 옮길 수 있도록 돕습니다.

Season1부터 Season 3까지 진행되었던 Microsoft AI Genius 시리즈에서는 지능형 에이전트 구축의 기초부터 실제 시스템과의 통합, 그리고 Microsoft·GitHub의 최신 혁신을 다뤘습니다. 프로덕션 레디 에이전트 아키텍처, GitHub 최적화, 멀티모달 프로토타이핑, 에이전트-투-에이전트(A2A) 오케스트레이션까지, 아시아 지역 개발자들이 바로 따라 할 수 있는 실습 중심으로 진행했습니다.

Season4의 새로운 점은 무엇인가요?
Season 4는 기존의 탄탄한 기반 위에, 더 실전적이고 실행 중심의 내용을 더했습니다. 에이전틱 AI를 개발 라이프사이클 전반의 일상적인 워크플로에 어떻게 자연스럽게 녹여낼 수 있는지 단계별로 보여드립니다.

이번 시즌은 아래 3개의 실습형 에피소드로 구성되어 있습니다.

- Episode 1 | Microsoft Agent Framework 시작하기: 실무에 바로 쓰는 AI 에이전트 구축하기
추론하고 실행하며, 실제 시스템과 연동되는 실무형 AI 에이전트를 어떻게 설계하고 구현하는지 배웁니다.

- Episode 2 | SpecKit을 활용한 Agentic DevOps: Specs을 CI/CD로 전환하기 (GitHub Actions 기반)
최신 GitHub 도구를 활용해 자동화부터 오케스트레이션까지, 에이전틱 AI로 DevOps 워크플로를 어떻게 더 빠르고 매끄럽게 만들 수 있는지 살펴봅니다.

- Episode 3 | GitHub Copilot SDK로 나만의 개발 경험(DX) 업그레이드 하기
단순한 코드 자동완성을 넘어, Copilot을 확장해 더 똑똑하고 개인화된 개발자 경험을 만드는 방법을 배웁니다.

    SpecKit을 활용한 Agentic DevOps: Specs을 CI/CD로 전환하기 (GitHub Actions 기반)

    5:30 AM - 6:30 AM (UTC)

    DevOps 자동화는 단순 스크립트나 정적인 규칙에 머물러서는 안 됩니다. 이번 에피소드에서는 SpecKit과 GitHub Actions를 활용하여 스펙(spec)을 지능형 CI/CD 파이프라인으로 전환하는 방법을 중심으로, DevOps 워크플로우에 Agentic AI를 적용하는 방식을 살펴봅니다. 또한, 에이전트 기반 패턴이 어떻게 추론하고, 적응하며, 의사결정을 자동화하는 워크플로우를 가능하게 하는지 이해하고, 이를 통해 팀이 수작업을 줄여 더 빠르게 작업할 수 있는 방법을 배웁니다. 이 세션에서 다루는 내용 Agentic 패턴이 현대 DevOps 환경에 어떻게 적용되는지 SpecKit을 활용해 스펙을 CI/CD 워크플로우로 전환하는 방법 GitHub Actions을 통해 에이전트 기반 파이프라인을 구성하는 방법 지능형 자동화를 통해 배포 속도와 안정성을 향상시키는 방법 사용 기술 SpecKit GitHub Actions Agentic AI 패턴 GitHub 기반 CI/CD 파이프라인 추천 대상 DevOps 엔지니어 및 플랫폼 엔지니어 GitHub 기반 CI/CD를 운영·개발하는 개발자 스펙부터 배포까지 End-to-End 자동화를 고민하는 팀 AI 기반으로 더 스마트한 DevOps 워크플로우에 관심 있는 분
