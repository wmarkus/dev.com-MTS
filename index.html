    What the inventory does not prove

      A portable content handoff.
      Not an automatic platform sync.

      Keep the content model and route evidence in this repository. Build editable Framer templates after authorization, then apply the Figma design direction.

      1. Capture the authorized source. Permission has been granted. Finish the repository capture and reconcile routes, variants, assets and interactive states before connecting other platforms.
      2. Recreate before reducing. Build shared navigation, page templates, content records and redirects. Verify desktop and mobile fidelity, with no hidden omissions.
      3. Connect a Framer project. Use its project-scoped API or external-agent connection. Import structured content and create editable templates; a repository is not itself a Framer project.
      4. Reduce the footprint. Review keep, consolidate and remove decisions. Approve redirect targets before cutting pages.
      5. Apply Figma designs. Identify the existing file and component nodes. The official Figma-to-Framer plugin transfers editable layers; do not assume two-way synchronization.
